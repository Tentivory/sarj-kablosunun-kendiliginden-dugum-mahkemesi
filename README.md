# Şarj Kablosunun Kendiliğinden Düğüm Mahkemesi

Türkiye Cumhuriyeti Çekmece İçi Kablo Yargısı, 47. Daire.

Bu depo bir şakadır. Kablo değildir. Ama kablo gibi davranır: çekmeceye konur, ertesi sabah düğüm halinde bulunur, kimse itiraf etmez.

## Resmi iddia

Şarj kablosu, kullanıcı uyurken, fizik kanunlarını çiğneyerek kendiliğinden düğümlenir. Bu yazılım suçu çözmez. Suçu dosyalar. Dosya da düğümlenir.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Kablo da yoktur.

```bash
python3 mahkeme.py
python3 mahkeme.py --uzunluk 120 --marka "isimsiz büyük market" --suc "gece 03:14'te kendi kendine denizci düğümü"
```

## Ne yapar

1. Kabloyu sanık sandalyesine oturtur (sandalye de kabloyla bağlıdır, ironi kasıtlıdır).
2. Düğüm katsayısını hesaplar. Formül ciddidir. Sonuç değildir.
3. Karar yazar: beraat, para cezası olarak yeni bir kablo, ya da müebbet çekmece.
4. Altına damga, imza, tarih ve isim basar. Ciddi olan kısım damgadır. Ciddi olmayan kısım da damgadır.
